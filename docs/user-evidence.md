## 待验证假设

- 用户：对复杂文本有兴趣的普通读者或硕博研究者；范围仍宽，尚未确定首发细分。
- 文本：古代经典、哲学、人文社科和专业论文；可能为外语，也可能为母语。
- 替代方案：翻译器与通用聊天；切换成本、解释质量、原文关联、笔记积累各自的重要性未知。
- 入口：真实文本导入、内置 Reader 与 Gemini BYOK 是否适合核心用户，仍需任务证据。
- 回访：不知道 3 位为何回来，也不知道这一行为能否在非朋友用户中复现。

## 新证据记录规则

记录日期、匿名参与者编号、招募来源/关系、真实任务、原有工具、观察到的行为、
支持与反对判断、局限和对应路线图任务。区分原话、观察和解释。
只保存经允许的摘要，不把私人原文、API key 或用户身份提交到仓库。
人数更新必须附时间窗与来源；没有新记录时不得把历史数字更新为当前指标。
