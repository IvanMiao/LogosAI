## 实现

session 使用稳定地址；History 和保存成果使用查询参数定位。用户与 document 隔离的
版本化本地快照保存阅读布局、分栏比例、成果选择、History 查找现场和各面板的位置。
原文与成果以段落签名、段内比例恢复重排后的位置；用户交互取消初始延迟恢复。
关闭解释清理成果地址；版本选择更新成果地址；History 保留在顶栏，不另加常驻返回条。

云加载期间隐藏不匹配的缓存原文；未知 session 与已删除成果各有退路。
修复 Retry cloud sync 未重新执行云读取、以及远端 session 到达后深链仍等待的问题。
API 和云端 schema 不变，legacy 导入继续保留。

## 边界

未调用真实 Gemini、认证或云数据服务；mock 云恢复不能替代真实登录、断网恢复和
多标签页验证。没有完成 200% 缩放、屏幕阅读器或自然用户回访验收。
本地视图快照不跨设备同步；存储失败时内存回退仅限当前页面生命周期。
内容已变化且无法唯一匹配时回顶部；原生文本选区不恢复。
任务继续使用已有生命周期，未新增后台常驻执行能力。桌面默认双栏保持现状，
原文优先布局与常驻 agent 留在后续设计切片中。
